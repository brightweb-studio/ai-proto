# BW - AI PROTO (Bright Web AI Prototype System)

A production-ready AI agent prototyping architecture and design system based on Untitled UI standards.

## Project Structure

- **`.agents/`**: Autonomous agent skill packages, workflow rules, QA audit guidelines, UX patterns, and design resources.
- **`DESIGN_SYSTEM/`**:
  - `prototype_system.css` - Comprehensive CSS tokens, light/dark themes, components, and layout utilities.
  - `ui_kit_showcase.html` - Interactive showcase with live components, calculators, quizzes, and theme toggle.
- **`Resources/`**: Reference materials, guides, and prompt frameworks.
- **`.agents.zip`**: Standalone installable distribution of the `.agents` skill package.

## Quick Start

1. Open `DESIGN_SYSTEM/ui_kit_showcase.html` in your browser to explore the component library and interactive widgets.
2. Review `.agents/skills/bw-prototype-system/SKILL.md` for agent execution guidelines and prompt workflows.
